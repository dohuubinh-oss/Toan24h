ĐIỂM NHẤN CÔNG NGHỆ

Go Fiber Backend & Gemini AI Pool

Go Fiber cung cấp REST API siêu nhanh với độ trễ tối thiểu, chịu tải đồng thời lớn. Hệ thống tích hợp cụm Gemini AI Pool xoay vòng API key thông minh để phân tích đề thi và sinh công thức toán học LaTeX chuẩn xác.

TRẢI NGHIỆM HỌC TẬP

YouTube Shorts Player & KaTeX

  • Xem video dọc (Shorts) tối ưu cho mẹo giải nhanh toán học.
  • Đồng bộ danh sách bài học và điều hướng mượt mà.
  • Ghi chú lý thuyết và công thức toán học hiển thị trực tiếp với KaTeX / MathText.

TẦNG LƯU TRỮ VÀ BỘ ĐỆM

PostgreSQL 16 & Redis Cache

PostgreSQL đảm bảo toàn vẹn dữ liệu quan hệ cho người dùng, ngân hàng đề thi, bài tập và blogs. Redis chịu trách nhiệm kiểm tra token JWT, lưu vết phiên làm việc và cache luồng video dạng shorts để phản hồi tức thì.
